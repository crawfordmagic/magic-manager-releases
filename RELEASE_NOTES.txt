Three upgrades: (1) Recurring expenses — set an expense to repeat (Weekly / Bi-weekly / Monthly / Quarterly / Annually) with a start date you can backdate and an optional end; the app posts the entries automatically, backfilling from the start date, and you can stop any of them from the Expenses screen. (2) Per-service event messages — a message you set for each service now shows on a booked client's event hub after they sign. (3) Lead statuses are now a fixed set (New, Pending, Booked, Completed, Lost, Referral, Referred), you can define your own "Lost" reasons in Settings, and imports map onto the fixed statuses.
